# 2026-09-01

## 个税明细页面（图片素材版）

- 需求：把手机截图还原成 WEB 页面 —— M1 固定头部、M2 在下方上下滑动。
- 第一版用手写 HTML/CSS 重绘界面，边框比例不协调被否。
- **最终方案：直接用原始图片当素材**，不做任何重绘。
  - `assets/M1.jpg` → `position: fixed` 顶部固定
  - `assets/M2.jpg` → 长图放进 `overflow-y: auto` 容器，原生滚动
  - 关键技巧：M1 图片 `load` 后用 `getBoundingClientRect().height` 测实际渲染高度，回填给滚动容器的 `padding-top`，避免写死数值导致遮挡。
- 产出：`index.html` + `assets/{M1,M2}.jpg`

### 用户偏好（重要）
还原截图类页面时，**优先用原图切片拼装，不要手写 HTML/CSS 重绘 UI** —— 手写版细节（圆角、间距、比例）对不齐，反复返工。
